# BIK Cleaners POS — Windows Downloads

[Download the latest installer](https://github.com/bikworldapp-bikim/BIK-Cleaners-POS_Update/releases/latest/download/BIKCleanersPOS-win-Setup.exe)

Windows 10/11, 64-bit. The installer includes .NET and installs WebView2 when needed (internet required).

After installation, the first launch asks for an empty data folder, store name, address, and telephone number. These become the application's data location and store settings used on receipts. Existing configured installations keep their settings.

The app checks and downloads updates once at startup. For a manual check or to apply a downloaded version, open **Utilities > App updates**. Save your work, then select **Update and restart**. Updates preserve customer data and store settings.

This repository contains installers and update packages only. Source code is maintained in a separate private repository. No customer databases or account credentials are distributed here.

The installer is currently unsigned; Windows may display an unknown publisher warning. SHA256SUMS.txt is included with each release.
